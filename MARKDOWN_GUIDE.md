# Markdown Syntax Reference

This guide demonstrates the core Markdown syntax used in GitHub documentation.

## Headings

# Heading 1

## Heading 2

### Heading 3

## Text Formatting

**Bold text**  
*Italic text*  
~~Strikethrough text~~

## Unordered List

- Item A
- Item B
  - Nested item B1

## Ordered List

1. First step
2. Second step
3. Final step

## Inline Code

Use `print("Hello")` to print a message in Python.

## Fenced Code Block

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("Ankit"))
```
